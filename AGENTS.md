# AGENTS.md

This project is a **TanStack Start** + React + TypeScript + Tailwind CSS portfolio site.

## Commands

| Command          | Description                           |
| ---------------- | ------------------------------------- |
| `npm run dev`    | Start development server (`vite dev`) |
| `npm run build`  | Build for production (`vite build`)   |
| `npm run lint`   | Run ESLint                            |
| `npm run format` | Run Prettier (`prettier --write .`)   |

## Critical — Do Not Miss

- **`src/start.ts`** must exist. It defines CSRF middleware for server functions; without it, server functions are vulnerable to cross-site requests. The comment explicitly says: _"Start installs this automatically when src/start.ts is absent; defining the file opts out, so re-add it explicitly."_

- **`src/server.ts`** is the server entry point (Cloudflare/vercel). Do not remove the `normalizeCatastrophicSsrResponse` logic — it handles h3-swallowed error bodies.

- **`src/routes/`** uses file-based routing. Do **not** create `src/pages/`, `app/layout.tsx`, or `_app/index.tsx` — those are Next.js/Remix conventions. The only root layout is `src/routes/__root.tsx`.

- **`src/routeTree.gen.ts`** is auto-generated by the TanStack router plugin. **Do not edit by hand.** The routes README confirms: _"`routeTree.gen.ts` is auto-generated. Don't edit it by hand."_

- **Vite plugins** are configured by `@lovable.dev/vite-tanstack-config`. The config warns: _"do NOT add them manually or the app will break with duplicate plugins."_ If you need more plugins, pass additional config via `defineConfig({ vite: { ... } })`.

- **Path aliases**: `@/` maps to `src/` (from `tsconfig.json`). Components import as ` "@/components/..."` or ` "@/lib/..."`.

- **Tailwind CSS**: Config is in `components.json` (baseColor, css path, aliases). The CSS entry is `src/styles.css` with `@import "tailwindcss" source(none)`.

- **ESLint** has a `no-restricted-imports` guard for `server-only` with a custom message about TanStack Start's module-naming convention. If you need `server-only`, rename to `*.server.ts` or add `@tanstack/react-start/server-only`.

- **`src/lovable-error-reporting.ts`** — error reporting hook used by the editor preview. Do not remove the `window.__lovableReportRuntimeError` forwarding.

## Quick dev flow

```sh
npm i          # install deps
npm run dev    # start local dev server
# make changes...
npm run lint   # verify lint passes
npm run format # verify format passes
npm run build  # build for production
```
